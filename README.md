# Y9 PRO V5 — المرحلة 1 — كله من متصفح الموبايل (من غير أوامر)

## إزاي بيشتغل
GitHub نفسه بيفك الـzip، ويولّد المفاتيح، ويشفّر ويوقّع الإعدادات، ويبني الـAPK. مفيش حاجة بتتشغّل على تلفونك.
المفاتيح مش بتتخزن في أي مكان: كلها بتتولّد من **Y9_MASTER_KEY** (سر عندك في GitHub Secrets) كل مرة.

## الخطوات (مرة واحدة)
1. افتح github.com ← **New repository** ← الاسم `y9-app` ← **Public** ← ✔ Add a README ← Create.
2. **Settings** (لو مش ظاهر: ⋯ أو فعّل "Desktop site") ← **Secrets and variables** ← **Actions** ← **New repository secret**. اعمل اتنين:
   - `Y9_MASTER_KEY` = جملة سرية طويلة **24 حرف أو أكتر** (مثلًا 5-6 كلمات عشوائية + أرقام). **احفظ نسخة منها في مكان خاص — لو ضاعت مش هتتسترجع.**
   - `Y9_APP_PASSWORD` = كلمة مرور التطبيق اللي المستخدم هيكتبها (8 حروف أو أكتر).
3. ارجع للمستودع ← **Add file** ← **Create new file**. في خانة الاسم اكتب بالظبط: `.github/workflows/setup.yml` ← الصق محتوى ملف `setup.yml` ← **Commit changes**.
4. **Add file** ← **Upload files** ← اختار `Y9ProV5-phase1.zip` ← **Commit changes**.
5. افتح تبويب **Actions**: هتلاقي "Y9 build" شغّال (5–10 دقايق). لو ما اشتغلش لوحده: افتحه ← **Run workflow**.
6. لما يخلص: **Releases** ← **Y9 PRO V5 (latest)** ← نزّل `Y9-PRO-V5.apk` وثبّته (اسمح بالتثبيت من المتصفح).
   لو فشل: افتح التشغيل الفاشل وابعتلي نص الخطأ. تقدر كمان تجرّب Run workflow واختار `debug`.

## تغيير الإعدادات بعد كده
- الروابط والأسماء: افتح `config/config.json` ← ✏️ ← عدّل ← Commit. GitHub هيشفّر ويوقّع لوحده (دقيقة تقريبًا).
- كلمة المرور: غيّر السر `Y9_APP_PASSWORD` ← Actions ← Y9 build ← Run workflow ← **أطفي** "Also build a new APK". المستخدمين هيتطلب منهم الباسورد الجديد.
- فيديو الخلفية: ارفعه باسم `bg.mp4` جوه `app/src/main/res/raw/` ← Run workflow (الـAPK ON).

## تحذيرات مهمة
- **Y9_MASTER_KEY**: لو ضاع أو اتغيّر، كل المفاتيح بتتغيّر: التطبيقات المثبتة هترفض الإعدادات الجديدة ومش هتتحدّث فوق القديمة، والكل يمسح ويثبّت من جديد.
- المفتاح لازم يكون **طويل وعشوائي**: المستودع مفتوح، ومحترف يقدر يجرّب تخمين خارجي على المفاتيح المشتقة. السر ده مش بيظهر في أي ملف.
- الـAPK على صفحة Releases المفتوحة يقدر أي حد يحمّله؛ كلمة المرور هي اللي بتقفل الاستخدام.

## الأمان — بصراحة
- **التوقيع (ECDSA P-256)** هو الحماية الحقيقية: التطبيق بيتحقق منه قبل أي حاجة، فمفيش حد يقدر يغيّر الإعدادات أو الباسورد أو الروابط حتى لو المستودع مفتوح. مفتاح التوقيع بيتولّد جوه GitHub Actions بس.
- **التشفير (AES-256-GCM)** بيخبّي المحتوى عن اللي بيفتح الملف عادي، لكن مفتاحه جوه الـAPK فمحترف يقدر يستخرجه. متحطش في الملف أي حاجة سرية فعلًا.
- كلمة المرور بتتحفظ كـ **PBKDF2-SHA256 (120,000 تكرار)** + salt. اختار كلمة قوية.
- الإعدادات **بيانات فقط**: التطبيق مش بينفّذ أي كود جاي من الإنترنت، وبيرفض أي ملف أقدم (`seq`).
- التطبيق بيفتكر الباسورد الصح لحد ما الـhash يتغيّر، وساعتها يسأل تاني.

## متقدم (اختياري)
